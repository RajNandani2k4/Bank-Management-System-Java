# Bank Management System (Java)

A desktop-based Bank Management System developed using Java, Swing, AWT, JDBC, and MySQL. The application provides a graphical interface for basic banking operations and stores account and transaction details in a database.

## Features

- User account registration
- Login using card number and PIN
- Deposit and withdrawal operations
- Balance enquiry
- Mini statement
- PIN change
- Fast cash withdrawal
- MySQL database connectivity

## Technologies Used

- **Programming Language:** Java
- **GUI:** Java Swing and AWT
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** NetBeans

## Prerequisites

- Java JDK
- NetBeans IDE
- MySQL Server
- MySQL Connector/J

## Setup and Installation

1. Clone or download this repository.
2. Open the project in NetBeans IDE.
3. Create a MySQL database named `bankmanagementsystem`.
4. Configure the database connection using your local database credentials.
5. Ensure MySQL Connector/J is available to the project.
6. Run the main class from NetBeans.

## Database Configuration

The application connects to a MySQL database. Configure your local database username and password in your local configuration file.

**Security note:** Do not upload database passwords, private configuration files, or other secrets to GitHub.
